## Технические находки (важно для следующих фаз)

- **Рендерер и экспортные требования (выверено на Godot 4.7.2):** апстрим никогда не
  экспортировался из репозитория; для сборок нужны два шима в `project.godot`
  (в CI дописываются на лету, в форке Фазы 2 закрепятся явно):
  - `renderer/rendering_method.web="gl_compatibility"` — дефолтный Forward+ в Web не
    экспортируется; визуально проверить, что игра в нём выглядит приемлемо (часть эффектов
    — volumetric fog, MSAA 3D — в gl_compatibility недоступна);
  - `rendering/textures/vram_compression/import_etc2_astc=true` — без него в Godot 4.7
    Android-экспорт падает с прямой ошибкой, а Web-экспорт с мобильной компрессией —
    молча (пустой список «конфигурационных ошибок» в `can_export()`).
- **Логи GitHub Actions из этой песочницы не читаются** (заблокированы CDN
  `*.actions.githubusercontent.com` / `release-assets.githubusercontent.com`), поэтому в
  воркфлоу встроена самодиагностика: пред-экспортные дампы и вывод хвоста ошибок Годота в
  аннотации (`::error::`) и step summary — это единственный способ агента видеть ошибки сборки.
- **Диск песочницы позволяет держать полный клон апстрима** (~2.1 ГБ в `_upstream/`,
  вне git) для локальных экспериментов, но **скачать бинарники Годота локально нельзя** —
  локальная проверка сборок недоступна, вся верификация через CI.
- Google Play с 2026 требует target SDK 36; Android-пресет бейзлайна уже на 36.
