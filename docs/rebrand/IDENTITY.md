> Направление выбрано человеком 2026-09-17: **sci-fi мехи / орбитальный десант** —
> танки → модульные мехи, нации → корпорации/гильдии. Мехи хорошо ложатся на NFT:
> шасси и оружейные модули — отдельные торгуемые компоненты лоадаута (Фаза 6).
>
> Все имена ниже — **рабочие кандидаты** (легко и дёшево менять сейчас; финализирует
> человек). Если имя совпадает с чужим известным брендом — заменить до анонса

## 1. Название игры

**ФИНАЛЬНОЕ название (решение человека 2026-09-17): `Dropfire: Corporate Wars`**
(тайтл/вордмарк — `DROPFIRE`; выбрано после трейдмарк-находки по ORBITFALL™). Подзаголовок-слоган: *«Four corporations. One continent. Zero
mercy.»*

⚠️ **ТРЕЙДМАРК-НАХОДКА 2026-09-17 (ждёт решения человека):** `Orbitfall™` — товарный
знак Stonefield Games (настольная ККИ, orbitfalltcg.com) + есть слот ELK Studios с тем
же именем. Публиковаться под ORBITFALL без юридического клиренса — риск. Альтернативы
из кандидатов: «Dropfire» (компания DropFire Inc. закрыта, марки не в игровом классе)
и «Volt & Steel» (поле «VOLT» в играх плотное, точное совпадение не найдено).
Ренейм — это замена строк в project.godot/кредитах/сплэше + package id + identityUri
(делается одним коммитом, см. tools/rebrand_audit.py).

- Android package id (dev): `io.github.leo88q.orbitfall.dev`
- Android package id (prod, при публикации): выбрать своё доменное пространство,
  например `com.<ваш-домен>.orbitfall` — НЕ использовать пространство P1X.
