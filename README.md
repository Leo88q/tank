# tank (рабочее название)

Солана-адаптация форка открытой пошаговой тактики **Tanks of Freedom II** (MIT, P1X):
полный ребрендинг, кошелёк/ончейн-экономика, публикация в Solana dApp Store и монетизация
авторов пользовательских карт.

## Текущий статус

- **Фаза 0 (юридическая гигиена): завершена** — см. [LICENSE_NOTES.md](LICENSE_NOTES.md).
- **Фаза 1 (бейзлайн): в работе** — `.github/workflows/baseline.yml` собирает немодифицированный
  апстрим `P1X-in/tanks-of-freedom-ii` (закреплённый коммит) в Web- и Android-артефакты.
- Статус всех фаз и открытые решения: [PROJECT_STATUS.md](PROJECT_STATUS.md).
